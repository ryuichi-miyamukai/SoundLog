同期・AI設定（GitHub Gist / Gemini）

最終同期: —

GitHub の Settings > Developer settings > Personal access tokens (classic) で gist 権限のみ付与したトークンを作成してください。キーはこのブラウザ内のみに保存されます。

初回は空欄のまま「保存して同期」を押すと非公開Gist（soundlog_data.json）を自動作成します。トークン・Gist ID・Gemini APIキーは BookLog（booklog_data.json）とも自動共有され、同じGist内で別ファイルとして安全に同居します。

設定すると、自然な日本語の簡単な解説・英語ジャンルの自動生成に加え、各アルバムカードから「AIと深ぼる」で対話しながら音楽性や背景を深掘りできます。未設定時はWikipediaの日本語取得・自動翻訳で解説を補完します。

AIとアルバムを深ぼる

AIと自由に対話するには「同期・AI設定」で Gemini API キー（無料枠あり）を設定してください。
