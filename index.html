GitHub の Settings > Developer settings > Personal access tokens (classic) で gist 権限のみ付与したトークンを作成してください。キーはこのブラウザ内のみに保存されます。

初回は空欄のまま「保存して同期」を押すと非公開Gist（soundlog_data.json）を自動作成します。2台目の端末では同じトークンとGist IDを入力してください。

設定すると Gemini 2.5 Flash で自然な日本語のアルバム紹介文と英語ジャンルを生成します。未設定またはエラー時は自動でWikipedia（アルバム記事限定・英語記事は日本語へ自動翻訳）とMusicBrainzへフォールバックします。
